# Accuracy evaluation

Generated by `npm run eval` (`eval/evaluate.js`). Every trial uses a synthetic route with **known ground truth**, so errors are measured against the true vertices rather than eyeballed. Seeds are fixed, so the numbers are reproducible.

**Setup.** 50 random seeds per cell. Shots every 25 ft, each displaced sideways by uniform noise of ±*amplitude* (the "crew meander" model in `generateSyntheticRoute`). Reconstruction uses the app defaults (bend threshold 10°, min points per segment 5). The route is the app's sample route: 5 true vertices, 3 of them real bends (90°, 38°, 90°; run lengths 480, 260, 420 and 300 ft). A true bend counts as *found* if a reconstructed vertex lies within 15 ft of it.

## 5. Synthetic phone-GPS walk (drifting error)

A 2.2 km path with a gentle bend and a sharp turn, walked at 1.4 m/s with 1 Hz fixes. Position error **drifts** rather than jumping around (autocorrelated, about 3 m sigma), which is how handheld GPS actually behaves. The track goes through the real GPX importer, is projected to UTM, and is compared with the true line. "Survey grade" uses only the 24" pipe-width tolerance; "Phone" adds the 15 ft noise floor. Auto-tune is run with the Phone setting. Mean distance is from the true line to the result.

| Setting | Seeds | Mean vertices | Verdict (good / check / poor) | Mean distance from true line (ft) |
|---|---|---|---|---|
| Survey grade, 10° / 5 pts | 20 | 127 | 0 / 4 / 16 | 7.3 |
| Phone, 10° / 5 pts | 20 | 46 | 17 / 3 / 0 | 6.7 |
| Phone + Auto-tune | 20 | 19 | 20 / 0 / 0 | 5.0 |

The true path has 5 vertices. This is a synthetic model of GPS error, not field data.

## Caveats

- **Synthetic data only.** The noise model is uniform sideways displacement; real crews also have systematic offsets, instrument error and non-uniform spacing. Treat these numbers as a controlled comparison, not a field accuracy claim.
- The route has a single geometry. Different bend angles and run lengths will shift the numbers.
- Sections 1-3 use fixed settings (the app defaults, or the curve-demo settings) with no per-trial tuning; sections 4 and 5 also show what Auto-tune picks.
